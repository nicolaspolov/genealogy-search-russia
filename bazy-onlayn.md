# Онлайн-архивы и базы

Справочник к скиллу genealogy-search-russia. Состояние на осень 2026 года: порталы меняют
адреса, условия доступа и цены. Перед опорой на пункт проверить заново.

## 1. Общие закономерности

1. **Ноль не доказательство.** Пустая выдача бывает при сбое, таймауте, неполном индексе,
   неверном параметре. Перед «нет» — контрольный запрос с заведомо известным ответом.
2. **Поиск целыми словами и без морфологии.** Префиксы часто не работают («Ивановск» даёт
   ноль, «Ивановское» — десять). На архивных порталах поиск может, наоборот, резать слово до
   основы («Дубов» находит сотни дел про дубы): искать точной фразой. Перебирать словоформы
   и написания деревни.
3. **Выдача обрезана.** Часть баз показывает первые 20 строк и не листается. Дробить запрос по
   имени или месту.
4. **Нестабильная выдача.** Некоторые сайты при частых запросах или с адресов дата-центров
   отдают ограниченную или искажённую выдачу. Проверка: повторить тот же запрос — число
   результатов и места должны совпасть.
5. **Ограничения по адресу.** Часть российских сервисов открывается только с российских
   адресов, часть зарубежных закрыта для России.
6. **Массовая выкачка ведёт к блокировке учётки.** Смотреть образы во вьюере в человеческом
   темпе.
7. **Единица оплаты разная:** архив на сутки, одно дело, фонд. Читать прейскурант до оплаты.
   Подтверждение платежа приходит с задержкой: второй раз не платить.
8. **Номер листа из базы — указатель, не доказательство;** название дела может не совпадать с
   содержимым.
9. **Текстовый слой дешевле картинки:** распознанный текст, PDF-описи, поиск по электронным
   книгам — сначала их.

## 2. Россия: сквозные ресурсы

**Яндекс Архив (yandex.ru/archive)**
- Распознанные рукописи ряда региональных архивов (Вологда, Новгород, Москва и Подмосковье,
  Омск и др.; регионы добавляются). Есть не все регионы.
- Полнотекстовый поиск по рукописи: по корню и вариантам, с фильтром по архиву, все страницы
  выдачи. Пустой текст листа бывает сбоем. С осени 2026 поиск требует входа в Яндекс.
- Документы соседних губерний могут лежать в чужом архиве (например, в фонде консистории
  соседней епархии).

**FamilySearch (familysearch.org)**
- Бесплатно после регистрации. Индекс и микрофильмы метрик, ревизий, исповедных многих
  губерний. Поиск по связке «имя + имя отца + имя матери», имена в церковной форме.
- Часть плёнок открыта только в центрах FamilySearch. Из России сервис может быть недоступен.
- Каталог плёнок по архивам бывшей империи удобно смотреть на nashipredki.com.

**ГИС УИАД (online.archives.ru)**
- Справочный аппарат федеральных архивов (РГИА, РГАДА, ГАРФ, РГВИА и др.) и виртуальный
  читальный зал. Поиск по заголовкам бесплатно, просмотр оцифрованных дел платно. До оплаты
  прочитать полный заголовок дела.

**НЭБ (rusneb.ru) и Президентская библиотека (prlib.ru)**
- Оцифрованные памятные книжки губерний, списки населённых мест, епархиальные ведомости,
  газеты, справочники. Полнотекстовый поиск по фамилии и селу.

**Списки населённых мест и карты**
- Списки населённых мест губерний (Президентская библиотека, ГПИБ elib.shpl.ru, краеведы):
  селение → волость → приход. Читать указатель приходов в конце тома и список опечаток.
- retromap.ru, etomesto.ru — старые карты с наложением на современную.
- Нечитаемый топоним в документе — прогнать огрызком (две-три опорные буквы) по списку
  населённых мест волости.

**Война**
- **«Память народа»** (pamyat-naroda.ru): потери, награды, документы частей, военнопленные.
  Может требовать капчу.
- **ОБД «Мемориал»** (obd-memorial.ru): донесения о потерях, госпитальные списки, карточки
  военнопленных. Поле места рождения ищет целыми словами; выдача ограничена 20 строками —
  дробить запрос. Разграфлённый лист смотреть целиком с соседними записями.
- **«Подвиг народа»** — награды; данные доступны и через «Память народа».
- **gwar.mil.ru** — Первая мировая: потери, госпитали.
- **Arolsen Archives** (arolsen-archives.org) — остарбайтеры, узники лагерей, перемещённые лица.

**Репрессии**
- «Открытый список», «Возвращённые имена», региональные книги памяти, сводный поиск
  memsearch.org. Поиск нечёткий — сверять год и место. Уголовных дел там нет.
- Старая база жертв политического террора общества «Мемориал» (lists.memo.ru) с серверов не
  открывается; её копия с данными выложена на GitHub (репозиторий ivbeg/memoru).

**Кадры**
- **ls.rusarchives.ru** — где хранятся документы по личному составу ликвидированных
  организаций. Действующих организаций нет: кадры у них самих.

## 3. Региональные архивные порталы

Почти у каждого региона свой портал, часто со входом через Госуслуги.
- Оцифрованное смотрится онлайн, часто платно посуточно; неоцифрованное — в зале или копией.
  Признак неоцифрованного дела — нет просмотрщика или кнопка «подписаться на оцифровку».
- В адресе дела зашит код архива: чужой код даёт ложное «дело не найдено».
- Поиск по фамилии на портале ищет по заголовкам дел, а не по тексту метрик.
- Именные базы «сведения о человеке» (например, по записям 1900–1925 годов в Петербурге) —
  неполные индексы: ноль там не доказывает отсутствия.
- «Поиск по распознанным образам» для рукописных метрик почти бесполезен.
- Перед выводом «нет доступа» открыть контрольное дело: отличить свой отказ от сбоя портала.
- Многие архивы выкладывают открытые перечни метрических книг по приходам, ревизий по
  деревням, PDF-описи. Начинать с них.

## 4. Справочники, деревья, форумы

**Familio (familio.org)**
- Поиск по фамилии без учётной записи сразу по многим оцифрованным справочникам: ведомости
  справок о судимости (имя, отчество, возраст, губерния, уезд, волость, деревня приписки),
  книги памяти, списки участников Первой мировой и др. Справка о том, где встречается фамилия.
- Каталоги населённых мест губерний по уездам и волостям: полный список деревень волости.
  Поиск по деревне находит людей из неё в справочниках и деревьях.
- Деревья пользователей: другие исследователи часто ведут ту же деревню или приход. Писать
  владельцу и просить источники.
- Ловушки: справочник даёт имя, отчество, год и место, но не родство. У фамилии бывает
  несколько ареалов: совпадение отчества при записи из другой губернии ещё не родство.
  Каталог волости показывает записи порциями — долистать до конца.

**MyHeritage, Geni, Ancestry** — индексы и чужие деревья. Размечать находку: «скан
документа» / «индексная запись» / «чужое дерево без источника».

**Форум ВГД (forum.vgd.ru)** — ветки по уездам, приходам и фамилиям. Там спрашивают, какие
книги сохранились, где лежит фонд, кто уже работал с селом; есть частные индексы. Сведения
проверять документом.

## 5. Зарубежье и эмиграция

- **Польша (Царство Польское):** metryki.genealodzy.pl (сканы), geneteka.genealodzy.pl
  (индекс, сверять по скану), szukajwarchiwach.gov.pl (каталог). С 1868 года записи по-русски.
- **Украина, Беларусь, Прибалтика, Финляндия, Кавказ, Средняя Азия** — архивы этих стран, свои
  порталы и правила; доступ из России может быть ограничен.
- **Эмиграция:** Ellis Island (прибытие в США), фонд Бюро по делам российских эмигрантов в
  Маньчжурии (Харбин; хранится в Хабаровском крае), Arolsen Archives.
