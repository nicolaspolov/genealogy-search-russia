# Если сканы читает ИИ

Справочник к скиллу genealogy-search-russia. Для тех, кто поручает просмотр архивных сканов
языковой модели или агентам.

## 1. Качество

- **Контроль до доверия:** прогнать модель на 3–5 страницах с известным ответом.
- **Контрольная запись в каждой пачке.** Не опознана — масштаб не годится, пачку пересмотреть.
- **Масштаб:** мелкая копия — найти место; читать — фрагмент колонки в полном разрешении.
  API моделей (на 2026 год) уменьшают изображения больше ~1500–2000 px по длинной стороне,
  поэтому разворот целиком теряет буквы.
- **Скоропись XVIII века** ни одна модель уверенно не читает. Имена оттуда — после проверки
  глазами. Модель, которая честно ставит [?], полезнее уверенно ошибающейся.
- **Транскрипция модели — черновик.** Имена прямых предков сверять по фрагменту.
- **Списки из веб-страниц** вытаскивать по исходному тексту, а не пересказом: пересказ
  подгоняет ответ под вопрос.

## 2. Экономия и разделение работы

- **Дорого стоит просмотр картинки, а не скачивание.** Навигация без картинок: описи,
  оглавления, номера листов, имена и размеры файлов.
- **Короткие задания:** одна книга или 20–25 картинок; результат после каждого кадра в файл.
  В длинной сессии каждая новая картинка заново оплачивает предыдущие.
- **Младшая модель листает и отбирает попадания, старшая читает найденное.** Пустая пачка
  младшей модели — не «нет»: такой вывод делается только после контрольной записи или
  перепроверки сильной моделью или человеком.
- **Не платить дважды за массовую обработку** одного и того же (платный распознаватель и
  модель по всей книге). Второе чтение найденной записи — норма.
- **Смета до прогона:** страниц × цена.

## 3. Бережность к архивам

- Один агент на один сайт архива, один поток, паузы. Параллельная выкачка с одного портала
  быстро ведёт к блокировке.
- Смотреть во вьюере, как человек.
- Сайт просит вход, капчу или отказывает — не перебирать обходы, а сказать человеку, что
  сделать руками: войти, открыть страницу, прислать скриншот или файл.

## 4. Задание агенту

1. Вопрос: кто, событие, годы, приход.
2. Что известно и какая запись — контроль.
3. Лимит картинок и где остановиться.
4. Отчёт: дословная цитата (неуверенное в [?]), шифр, кадр, путь к фрагменту; статус
   «кандидат».
5. Пустой результат — с охватом: «в кадрах X–Y не встретилось; проверялись написания …».
6. Выше недоказанного звена — только с пометкой «гипотеза».
7. Не платить, не заказывать, никому не писать.
