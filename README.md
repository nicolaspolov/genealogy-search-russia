# Поиск предков в России — скилл для ИИ-помощников

Набор инструкций для Claude, Codex, Cursor и других ИИ-помощников: как искать предков в
Российской империи, СССР и России и не ошибаться. Метрические книги, ревизские сказки,
исповедные ведомости, ЗАГС, советские архивы, базы о войне и репрессиях, письма в архивы,
чтение старой рукописи.

Скилл учит помощника:
- начинать с того, что есть у человека дома, и вести его по шагам от одного ФИО до нужного
  архива;
- не принимать первую найденную запись с тем же именем за «нашего» человека;
- не говорить «записи нет», пока не проверено, туда ли смотрели и сколько просмотрели;
- не тратить деньги на запросы, пока не исчерпано бесплатное.

## Установка

Скопируйте папку со всеми файлами (имя папки — `genealogy-search-russia`):

| Инструмент | Куда положить |
|---|---|
| Claude Code | `~/.claude/skills/genealogy-search-russia/` |
| Codex CLI, Gemini CLI, Copilot CLI | `~/.agents/skills/genealogy-search-russia/` |
| Claude.ai | Настройки → Возможности → Скиллы → загрузить zip-архив папки |
| Cursor | папка скиллов, если версия их поддерживает; иначе текст `SKILL.md` в `.cursor/rules/` или `AGENTS.md` проекта, остальные файлы рядом |
| ChatGPT и другие чаты | `SKILL.md` — в инструкции проекта, остальные файлы — в файлы проекта |

```bash
git clone https://github.com/nicolaspolov/genealogy-search-russia.git ~/.claude/skills/genealogy-search-russia
```

Помощник подключает скилл сам, когда разговор заходит о родословной, предках, архивах,
«Памяти народа» и т. п.

## Важно
