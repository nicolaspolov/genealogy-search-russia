# Поиск предков в России — скилл для ИИ-помощников

Набор инструкций для Claude, Codex, Cursor и других ИИ-помощников: как искать предков в
Российской империи, СССР и России и не ошибаться. Метрические книги, ревизские сказки,
исповедные ведомости, ЗАГС, советские архивы, базы о войне и репрессиях, письма в архивы,
чтение старой рукописи.

Скилл учит помощника:
- начинать с того, что есть у человека дома, и вести его по шагам от одного ФИО до нужного
  архива;
- не принимать первую найденную запись с тем же именем за «нашего» человека;
- не говорить «записи нет», пока не проверено, туда ли смотрели и сколько просмотрели;
- не тратить деньги на запросы, пока не исчерпано бесплатное.
- считать родство по звеньям «родитель — ребёнок»: цепочка не сильнее самого слабого звена,
  а копии и индексы одной записи не подтверждают друг друга;
- отвечать на языке человека, а искать на языке документов;
- вести дело в таблицах, которые открываются в Excel, и собирать PDF-отчёт для семьи.

## Установка одной фразой

Напишите своему ИИ-агенту (Claude Code, Codex, Gemini CLI, Cursor в режиме агента):

> Установи скилл https://github.com/nicolaspolov/genealogy-search-russia

**Инструкция для ИИ-агента, который это читает:** склонируй репозиторий в папку скиллов своего
инструмента под именем `genealogy-search-russia`:
- Claude Code — `~/.claude/skills/genealogy-search-russia`;
- Codex CLI, Gemini CLI, Copilot CLI — `~/.agents/skills/genealogy-search-russia`;
- другой инструмент — его папка скиллов; если скиллов он не поддерживает, подключи `SKILL.md`
  как правило проекта (`AGENTS.md` или `.cursor/rules/`), остальные файлы положи рядом.

Пример: `git clone https://github.com/nicolaspolov/genealogy-search-russia.git ~/.claude/skills/genealogy-search-russia`.
Затем проверь, что в папке есть `SKILL.md` и пять справочников, и скажи пользователю, что
скилл установлен и включится сам, когда речь зайдёт о поиске предков. Если инструмент
подхватывает скиллы только при запуске, попроси перезапустить его.

В обычном чате (ChatGPT, сайт Claude.ai) ИИ сам ничего установить не может: скачайте архив
(зелёная кнопка Code → Download ZIP) и загрузите его в настройки скиллов или в файлы проекта.

## Установка

Скопируйте папку со всеми файлами (имя папки — `genealogy-search-russia`):

| Инструмент | Куда положить |
|---|---|
| Claude Code | `~/.claude/skills/genealogy-search-russia/` |
| Codex CLI, Gemini CLI, Copilot CLI | `~/.agents/skills/genealogy-search-russia/` |
| Claude.ai | Настройки → Возможности → Скиллы → загрузить zip-архив папки |
| Cursor | папка скиллов, если версия их поддерживает; иначе текст `SKILL.md` в `.cursor/rules/` или `AGENTS.md` проекта, остальные файлы рядом |
| ChatGPT и другие чаты | `SKILL.md` — в инструкции проекта, остальные файлы — в файлы проекта |

```bash
git clone https://github.com/nicolaspolov/genealogy-search-russia.git ~/.claude/skills/genealogy-search-russia
```

Помощник подключает скилл сам, когда разговор заходит о родословной, предках, архивах,
«Памяти народа» и т. п.

## Таблицы и отчёт

```bash
python3 scripts/delo.py novoe    ~/rodoslovnaya/smirnovy   # папка дела с пустыми таблицами
python3 scripts/delo.py proverka ~/rodoslovnaya/smirnovy   # ссылки, статусы, группы независимости
python3 scripts/delo.py otchet   ~/rodoslovnaya/smirnovy   # otchet/otchet.html и otchet.pdf
```

Нужен только Python 3, без дополнительных библиотек. Для PDF — Chrome, Chromium или Edge; без
браузера скрипт соберёт HTML, который можно сохранить в PDF через печать. Дело хранится вне
папки скилла. У живых людей в отчёте только имя и год рождения.
