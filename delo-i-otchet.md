# Дело: таблицы, статусы, отчёт

Справочник к скиллу genealogy-search-russia. Как вести исследование в четырёх таблицах и
собрать отчёт для семьи. Для короткого вопроса («кто такой человек в этой записи») таблицы
не нужны; они окупаются, когда в деле больше пяти человек или нескольких веток.

## 1. Завести дело

```bash
python3 scripts/delo.py novoe ~/rodoslovnaya/smirnovy
```

Папка дела создаётся вне папки скилла (личные данные отдельно от скилла). Внутри:
`delo.md`, четыре таблицы и папка `kopii/` для сканов и фото документов. Таблицы — CSV с
разделителем «;», открываются в Excel и LibreOffice. Списки внутри поля писать через запятую
(`D1, D4`). Если ИИ дописывает таблицы сам — через модуль `csv`, чтобы поля с «;» попадали в
кавычки.

## 2. Таблицы

**delo.md** — вопрос, главный человек (его id), язык отчёта, что известно до поиска, кто из
упомянутых жив и согласен, итог в 3–5 строк, открытые вопросы.

**lyudi.csv — люди.** Один человек — одна строка; тёзки до доказательства — разные строки.
`id` (P1, P2…), `имя_как_в_документе`, `варианты_написания`, `пол`, `рождение`,
`место_рождения`, `смерть`, `место_смерти`, `сословие_занятие`, `вероисповедание`,
`жив` (да / нет / неизвестно), `документы` (id через запятую), `примечание`.

**dokumenty.csv — документы и всё, что им кажется.** Метрика, скан, индексная запись, чужое
древо, рассказ родственника — каждое отдельной строкой.
`id` (D1…), `что_за_документ`, `дата_документа`, `архив_шифр`, `сайт_и_кадр`, `вид`,
`группа`, `читаемость`, `файл`, `что_говорит`, `найден`.
- `вид`: оригинал, скан оригинала, копия, выписка, справка, публикация, индекс, дерево,
  рассказ. Последние три — наводки: доказать ими связь нельзя.
- `группа` — **группа независимости**: всё, что восходит к одной записи, получает одну
  группу. Метрика, её консисторская копия, индекс этой метрики на сайте и выписка из неё —
  одна группа. Запись о смерти через 70 лет, составленная со слов другого человека, — другая
  группа. Подтверждение засчитывается только из другой группы.

**svyazi.csv — связи, по одному звену.** Каждая строка — одно ребро: родитель — ребёнок или
супруги. «Прадед» — это три строки, а не одна.
`id` (S1…), `кто`, `кем_приходится` (отец, мать, муж, жена, сын, дочь, брат, сестра), `кому`,
`статус`, `прямой_документ`, `подтверждения`, `против`, `что_проверить`.
Пример: `S1; P2; отец; P1` — P2 отец P1.

**poisk.csv — журнал поиска,** включая пустые результаты.
`дата`, `где`, `что_искали`, `запрос_или_шифр`, `написания`, `охват` (годы, части книги, листы
или кадры), `контрольная_запись`, `результат`, `найдено` (id документов), `дальше`.

## 3. Статусы связи

| Статус | Когда ставить |
|---|---|
| доказано | есть **прямой документ** о связи (метрика называет родителей; исповедная — «жена его, дети их») **и** подтверждение из **другой группы**, что в нём те же люди; документов против нет |
| вероятно | признаки сходятся, но нет прямого документа или нет независимого подтверждения |
| гипотеза | рабочее предположение, документа пока нет |
| спорно | есть документ против, противоречие не разрешено |
| опровергнуто | документы показывают, что связи нет |

Правила:
- **Цепочка не сильнее самого слабого звена.** Прадед «доказано» только если доказаны все три
  звена до него. В отчёте у каждого предка статус цепочки, а не только последнего звена.
- **Копии и индексы одной записи не подтверждают друг друга.** Отсюда и группы.
- **Отчество само по себе не доказывает отцовство,** общая фамилия — родство, жизнь в одном
  дворе — что жена во дворе мать детей.
- Личность (что запись о нашем человеке) и связь (что он отец именно этого ребёнка)
  оцениваются отдельно.
- Статус не повышать ради прохождения проверки: «вероятно» и «гипотеза» — честный рабочий
  результат.

## 4. Проверка

```bash
python3 scripts/delo.py proverka ~/rodoslovnaya/smirnovy
```

Ошибки (отчёт не соберётся): ссылки на несуществующих людей и документы, повтор id, статус не
из списка, «доказано» без прямого документа или без подтверждения из другой группы, «доказано»
при документах против, наводка (индекс, дерево, рассказ) в роли прямого документа.
Предупреждения: документ без группы, отрицательный результат поиска без охвата, живые люди.

## 5. Отчёт

```bash
python3 scripts/delo.py otchet ~/rodoslovnaya/smirnovy
```

В папке `otchet/` появляются `otchet.html` и `otchet.pdf`: главное, объяснение статусов,
предки по поколениям со статусом цепочки, связи по звеньям, карточки людей, документы с
шифрами, где искали, что дальше. Для PDF нужен Chrome, Chromium или Edge; если браузера нет —
открыть HTML и сохранить через «Печать → Сохранить как PDF».

- У живых людей в отчёте только имя и год рождения. Полный вид для себя — ключ `--polnyi`;
  такой отчёт не пересылать без согласия этих людей.
- Перед отправкой родне перечитать «Главное» в `delo.md`: отчёт открывается им.
